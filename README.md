# Garage Town

Jogo social de oficina em 2D isométrico (nome provisório). Spec em `docs/superpowers/specs/`.

## Rodar

```bash
pnpm i
pnpm dev        # http://localhost:5173
pnpm test       # testes unitários (Vitest)
pnpm typecheck
pnpm lint
pnpm build
pnpm build --mode test && pnpm e2e   # testes end-to-end (Playwright)
```
